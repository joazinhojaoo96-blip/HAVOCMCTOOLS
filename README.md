# HAVOCMC TOOLS

Conversor Java → Bedrock baseado no núcleo do GeyserConverter.

## Cloudflare Pages
- Build command: `pnpm build`
- Output directory: `apps/web/dist`
- Node.js: 20+ (22 recomendado)
- Sem API/server: a conversão roda no navegador em Web Worker.

## Local
`pnpm install` → `pnpm dev`
